# SymQG 索引结构布局图

## 1. 单个顶点（数据点）的内存布局

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        顶点 i 的内存布局 (row_offset_ 字节)                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ 偏移 0                                                                      │
│ ┌─────────────────────────────────────────────────────────────────────┐   │
│ │ 原始向量 (Raw Vector)                                                 │   │
│ │ 大小: dim_ * sizeof(T) 字节                                           │   │
│ │ 内容: [v0, v1, v2, ..., v_{dim_-1}]                                  │   │
│ │ 用途: 存储数据点的原始特征向量，用于精确距离计算                       │   │
│ └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 偏移 batch_data_offset_ = dim_ * sizeof(T)                                 │
│ ┌─────────────────────────────────────────────────────────────────────┐   │
│ │ Batch Data 区域                                                      │   │
│ │ 大小: (degree_bound_ / 32) * QGBatchDataMap::data_bytes(padded_dim_)│   │
│ │                                                                      │   │
│ │ ┌───────────────────────────────────────────────────────────────┐   │   │
│ │ │ Batch 0 (邻居 0-31)                                            │   │   │
│ │ │ ┌─────────────────────────────────────────────────────────┐   │   │   │
│ │ │ │ batch_bin_code_: padded_dim * 32 / 8 字节               │   │   │   │
│ │ │ │ [neighbor0_code] [neighbor1_code] ... [neighbor31_code] │   │   │   │
│ │ │ └─────────────────────────────────────────────────────────┘   │   │   │
│ │ │ ┌─────────────────────────────────────────────────────────┐   │   │   │
│ │ │ │ f_add_: 32 * sizeof(T) 字节                             │   │   │   │
│ │ │ │ [f_add_0, f_add_1, ..., f_add_31]                       │   │   │   │
│ │ │ └─────────────────────────────────────────────────────────┘   │   │   │
│ │ │ ┌─────────────────────────────────────────────────────────┐   │   │   │
│ │ │ │ f_rescale_: 32 * sizeof(T) 字节                         │   │   │   │
│ │ │ │ [f_rescale_0, f_rescale_1, ..., f_rescale_31]           │   │   │   │
│ │ │ └─────────────────────────────────────────────────────────┘   │   │   │
│ │ └───────────────────────────────────────────────────────────────┘   │   │
│ │                                                                      │   │
│ │ ┌───────────────────────────────────────────────────────────────┐   │   │
│ │ │ Batch 1 (邻居 32-63)                                           │   │   │
│ │ │ [相同的结构]                                                   │   │   │
│ │ └───────────────────────────────────────────────────────────────┘   │   │
│ │                                                                      │   │
│ │ ... (共 degree_bound_ / 32 个batch)                                │   │
│ └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 偏移 neighbor_offset_ = batch_data_offset_ +                                │
│                        (degree_bound_/32) * QGBatchDataMap::data_bytes()   │
│ ┌─────────────────────────────────────────────────────────────────────┐   │
│ │ 邻居ID列表 (Neighbor IDs)                                           │   │
│ │ 大小: degree_bound_ * sizeof(PID) 字节                              │   │
│ │ 内容: [neighbor_id_0, neighbor_id_1, ..., neighbor_id_{degree-1}]  │   │
│ │ 用途: 存储该顶点的所有邻居顶点ID                                     │   │
│ └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 总大小: row_offset_ = neighbor_offset_ + degree_bound_ * sizeof(PID)     │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. Batch Data 详细结构（单个Batch，32个邻居）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                   单个Batch的内存布局 (32个邻居)                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ 偏移 0                                                                      │
│ ┌─────────────────────────────────────────────────────────────────────┐   │
│ │ batch_bin_code_ (二进制量化码)                                      │   │
│ │ 大小: padded_dim * 32 / 8 字节                                       │   │
│ │ 布局:                                                                 │   │
│ │   [neighbor0_bit0...bit_{padded_dim-1}]  (padded_dim bits)          │   │
│ │   [neighbor1_bit0...bit_{padded_dim-1}]  (padded_dim bits)          │   │
│ │   ...                                                                 │   │
│ │   [neighbor31_bit0...bit_{padded_dim-1}] (padded_dim bits)          │   │
│ │ 存储: 每个邻居用1-bit编码，共32个邻居，打包成字节数组                  │   │
│ └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 偏移 padded_dim * 32 / 8                                                   │
│ ┌─────────────────────────────────────────────────────────────────────┐   │
│ │ f_add_ (加法因子数组)                                                │   │
│ │ 大小: 32 * sizeof(T) 字节                                             │   │
│ │ 布局: [f_add[0], f_add[1], ..., f_add[31]]                           │   │
│ │ 用途: 用于距离估计的加法项                                            │   │
│ └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 偏移 padded_dim * 32 / 8 + 32 * sizeof(T)                                 │
│ ┌─────────────────────────────────────────────────────────────────────┐   │
│ │ f_rescale_ (重缩放因子数组)                                          │   │
│ │ 大小: 32 * sizeof(T) 字节                                             │   │
│ │ 布局: [f_rescale[0], f_rescale[1], ..., f_rescale[31]]              │   │
│ │ 用途: 用于距离估计的缩放项                                            │   │
│ └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 总大小: (padded_dim * 32 / 8) + (32 * sizeof(T) * 2)                      │
│        = padded_dim * 4 + 64 * sizeof(T)  (假设T=float, 则=256字节)      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 内存访问模式

### 4.1 获取顶点i的数据

```cpp
// 获取原始向量
T* vector = get_vector(i);
// 地址: data_ + i * row_offset_

// 获取batch_data
char* batch_data = get_batch_data(i);
// 地址: data_ + i * row_offset_ + batch_data_offset_

// 获取邻居ID列表
PID* neighbors = get_neighbors(i);
// 地址: data_ + i * row_offset_ + neighbor_offset_
```

### 4.2 访问batch中的邻居

```cpp
// 访问第j个batch（包含邻居 j*32 到 (j+1)*32-1）
char* batch_j = get_batch_data(i) + j * QGBatchDataMap::data_bytes(padded_dim_);

// 解析batch数据
QGBatchDataMap<T> batch(batch_j, padded_dim_);
uint8_t* codes = batch.bin_code();      // 32个邻居的量化码
T* f_add = batch.f_add();                // 32个加法因子
T* f_rescale = batch.f_rescale();        // 32个缩放因子

// 获取对应的邻居ID
PID* neighbor_ids = get_neighbors(i);
PID neighbor_k = neighbor_ids[j * 32 + k];  // 第j个batch中的第k个邻居
```

## 5. 构建流程数据流图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          构建流程数据流                                   │
└─────────────────────────────────────────────────────────────────────────┘

初始化阶段:
    原始数据 → 计算质心 → 选择入口点 → 复制向量到索引
                    ↓
    随机初始化:
        为每个顶点随机选择 degree_bound_ 个邻居
        计算精确距离
        量化编码 → 存储到batch_data
                    ↓
    迭代优化 (3次):
        ┌─────────────────────────────────────────┐
        │ 迭代 i (i = 1, 2, 3)                   │
        ├─────────────────────────────────────────┤
        │ 1. 搜索新邻居                           │
        │    - 使用当前图进行ANN搜索              │
        │    - 找到 ef_build_ 个候选             │
        │    - 加入当前邻居                       │
        │    - 部分排序                           │
        │         ↓                               │
        │ 2. 启发式剪枝                           │
        │    - 贪心选择 degree_bound_ 个邻居      │
        │    - 记录被剪枝的邻居（最后一次迭代）   │
        │         ↓                               │
        │ 3. 添加反向边                           │
        │    - 确保图的对称性                     │
        │    - 对溢出顶点进行剪枝                 │
        │         ↓                               │
        │ 4. 图精炼（仅最后一次迭代）             │
        │    - 补充不足的邻居                     │
        │    - 使用二分搜索优化阈值               │
        │         ↓                               │
        │ 5. 更新量化编码                         │
        │    - 旋转向量                           │
        │    - 批量量化邻居                       │
        │    - 存储到batch_data                   │
        └─────────────────────────────────────────┘
                    ↓
    保存索引到文件
```

## 6. 搜索流程数据流图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          搜索流程数据流                                   │
└─────────────────────────────────────────────────────────────────────────┘

输入: 查询向量 query, top-k, ef
        ↓
旋转查询向量: rotated_query = rotator.rotate(query)
        ↓
初始化:
    - search_pool (大小=ef): 搜索缓冲区
    - res_pool (大小=k): 结果缓冲区
    - visited_set: 访问标记
    - 将入口点加入search_pool
        ↓
主循环 (while search_pool不为空):
    ┌─────────────────────────────────────────┐
    │ 1. 弹出距离最小的节点 cur_node          │
    │    - 如果已访问，跳过                    │
    │    - 标记为已访问                        │
    │         ↓                                │
    │ 2. 计算精确距离                          │
    │    exact_dist = dist(query, vector[cur]) │
    │         ↓                                │
    │ 3. 扫描邻居 (scan_neighbors)            │
    │    ┌──────────────────────────────────┐ │
    │    │ 对每个batch (32个邻居):          │ │
    │    │   - 使用量化码估计距离            │ │
    │    │   - 批量计算32个估计距离          │ │
    │    │                                  │ │
    │    │ 对每个邻居:                      │ │
    │    │   - 如果未访问且search_pool未满: │ │
    │    │   - 使用估计距离加入search_pool  │ │
    │    └──────────────────────────────────┘ │
    │         ↓                                │
    │ 4. 将cur_node加入res_pool                │
    │    - 使用精确距离                        │
    └─────────────────────────────────────────┘
        ↓
更新结果 (update_results):
    - 检查res_pool中节点的邻居
    - 补充未访问的邻居到结果
        ↓
返回top-k结果
```

## 7. 量化编码原理

### 7.1 量化过程

```
对于顶点i和其邻居j:

1. 旋转向量:
   rotated_i = rotator.rotate(vector[i])  // 质心
   rotated_j = rotator.rotate(vector[j])  // 邻居

2. 计算残差:
   residual = rotated_j - rotated_i

3. 1-bit量化:
   bit_k = sign(residual[k])  // 每个维度1 bit

4. 计算因子:
   f_add = 量化相关的加法项
   f_rescale = 量化相关的缩放项

5. 存储:
   batch_bin_code: 打包的二进制码
   f_add: 加法因子
   f_rescale: 缩放因子
```

### 7.2 距离估计

```
使用量化码估计距离:

1. 旋转查询向量:
   rotated_query = rotator.rotate(query)

2. 计算内积:
   inner_product = fast_bitwise_dot(batch_bin_code, rotated_query)

3. 应用因子:
   estimated_dist = f_rescale * inner_product + f_add

4. 返回估计距离
```

## 8. 内存对齐和优化

- **对齐**: 使用`AlignedAllocator`，对齐到4MB边界（1 << 22）
- **SIMD优化**: `padded_dim_`必须是64的倍数，支持AVX-512指令
- **批量处理**: 每次处理32个邻居，利用SIMD批量计算
- **内存预取**: 在扫描邻居时预取下一个可能访问的向量

## 9. 关键参数说明

| 参数 | 说明 | 约束 |
|------|------|------|
| `degree_bound_` | 每个顶点的最大邻居数 | 必须是32的倍数 |
| `dim_` | 原始向量维度 | 任意正整数 |
| `padded_dim_` | 填充后的维度 | 必须是64的倍数，>= dim_ |
| `ef_build_` | 构建时的搜索宽度 | 建议 >= degree_bound_ |
| `ef` | 查询时的搜索宽度 | 影响查询质量和速度 |
| `kBatchSize` | 批量大小 | 固定为32 |

## 10. 存储空间计算

假设：
- `num_points_` = N
- `dim_` = D
- `degree_bound_` = M (32的倍数)
- `padded_dim_` = P (64的倍数)
- `sizeof(T)` = 4 (float)
- `sizeof(PID)` = 4 (uint32_t)

单个顶点的存储空间：
```
row_offset_ = dim_ * sizeof(T)                                    // 原始向量
            + (degree_bound_ / 32) * QGBatchDataMap::data_bytes()  // batch_data
            + degree_bound_ * sizeof(PID)                          // 邻居ID

其中:
QGBatchDataMap::data_bytes() = (padded_dim * 32 / 8) + (32 * sizeof(T) * 2)
                             = padded_dim * 4 + 256

因此:
row_offset_ = D * 4 + (M/32) * (P * 4 + 256) + M * 4
            = 4D + M * (P/8 + 4) + 8M
            = 4D + M * (P/8 + 12)
```

总存储空间：
```
总空间 = N * row_offset_ 字节
```

示例（D=128, M=64, P=128, N=1M）：
```
row_offset_ = 4 * 128 + 64 * (128/8 + 12) = 512 + 64 * 28 = 2304 字节
总空间 = 1,000,000 * 2304 = 2.304 GB
```
